# プロジェクト固有ルール（hirudoki）

「ひるどき」は、日替わりの弁当を注文すると自宅やオフィスまで届けてくれる宅配サイトです。 利用者はその日の献立を見て注文し、管理者は献立・注文・配達を管理します。

## 国際化（i18n）

- 日時表示は `I18n.l` を使用
